Climate Projection Data

CMIP6 climate projections for the SEA Provinces model and TCCIP projections for the Taiwan BSA model

Climate projection data informs both study arms, but from different sources suited to each geography:

  • Arm 1 (SEA Provinces): CMIP6 multi-model ensemble projections and Global Warming Level (GWL) datasets are used to compute the bias correction delta that adjusts current ERA5-Land observations back into the model’s 2011–2018 training distribution.
  • Arm 2 (Taiwan BSA): TCCIP (Taiwan Climate Change Projection Information and Adaptation Knowledge Platform) provides high-resolution downscaled projections specifically for Taiwan, used to quantify future dengue suitability under different warming scenarios.

## Arm 1 — Southeast Asia Provinces (CMIP6 / GWL)

### Global Warming Level Projections (SEA Domain)

Summary of regional climate trajectories from the GWL dataset covering the SEA domain.
These trajectories are used to compute the monthly bias correction applied before STGNN inference.

```{python}
#| echo: false
#| label: fig-gwl-temp
#| fig-cap: "Mean temperature trajectories across Global Warming Levels for the SEA region."

import plotly.graph_objects as go

gwl_path = pathlib.Path("../climate-projection-module/data/processed/TSV/GWL_NetCDF/gwl_all_sliced.tsv")

gwl_monthly = pd.DataFrame()
if not gwl_path.exists():
    print("⚠️  GWL TSV not found — run climate-projection-module pipeline first.")
else:
    gwl = pd.read_csv(gwl_path, sep="\t", parse_dates=["time"])
    if gwl.empty:
        print("⚠️  GWL TSV is empty — no data to plot.")
    else:
        gwl_monthly = gwl.groupby(["gwl", gwl["time"].dt.to_period("M")]).mean(numeric_only=True).reset_index()
        gwl_monthly["time"] = gwl_monthly["time"].astype(str)

        fig = go.Figure()
        for gwl_val in sorted(gwl_monthly["gwl"].unique()):
            subset = gwl_monthly[gwl_monthly["gwl"] == gwl_val]
            fig.add_trace(go.Scatter(
                x=subset["time"], y=subset["temp_avg"],
                mode="lines", name=f"GWL {gwl_val}°C",
            ))
        fig.update_layout(
            title="Mean Temperature by Global Warming Level — SEA",
            xaxis_title="Month", yaxis_title="Temperature (°C)",
            legend_title="GWL Scenario", height=400,
        )
        fig.show()
```

### CMIP6 SSP2-4.5 Bias Correction Baseline

The bias correction applied to operational inference computes the difference between the CMIP6 SSP2-4.5
projected climatology for the current calendar month and the 2011–2018 ERA5-Land training climatology.
This delta is subtracted from current observations before they are passed to the STGNN.

```{python}
#| echo: false
#| label: tbl-bias-correction
#| tbl-cap: "Monthly bias correction deltas (CMIP6 SSP2-4.5 minus 2011–2018 ERA5 baseline) across all calendar months."

deltas_path = pathlib.Path("data/climate_deltas.json")
import json

if not deltas_path.exists():
    print("⚠️  climate_deltas.json not found — run site/scripts/apply_climate_delta.py first.")
else:
    deltas = json.loads(deltas_path.read_text())
    rows = []
    for month, feat_dict in deltas.items():
        if month == "annual_mean":
            continue
        for feat, val in feat_dict.items():
            rows.append({"Month": month, "Feature": feat, "Delta": round(val, 4)})
    if not rows:
        print("⚠️  climate_deltas.json has no per-month data — run site/scripts/apply_climate_delta.py first.")
    else:
        df_deltas = pd.DataFrame(rows).pivot(index="Month", columns="Feature", values="Delta")
        df_deltas.style.format(precision=4).background_gradient(cmap="RdBu_r", axis=None)
```

```{python}
#| echo: false
#| label: fig-tccip-temp
#| fig-cap: "Placeholder: TCCIP mean temperature projections for Taiwan counties under RCP4.5 and RCP8.5, 2020–2099."

tccip_path = climate_dir / "TSV/TCCIP/tccip_county_temperature.tsv"
if not tccip_path.exists():
    print("⚠️  TCCIP temperature TSV not found — run climate-projection-module/scripts/extract_tccip.py first.")
else:
    df = pd.read_csv(tccip_path, sep="\t", parse_dates=["year"])
    if df.empty or "scenario" not in df.columns:
        print("⚠️  TCCIP temperature TSV is empty or missing expected columns.")
    else:
        fig = go.Figure()
        for scenario in df["scenario"].unique():
            subset = df[df["scenario"] == scenario]
            fig.add_trace(go.Scatter(
                x=subset["year"], y=subset["temp_mean"],
                mode="lines", name=scenario,
            ))
        fig.update_layout(
            title="TCCIP Mean Temperature Projections — Taiwan",
            xaxis_title="Year", yaxis_title="Temperature (°C)",
            legend_title="Scenario", height=400,
        )
        fig.show()
```
