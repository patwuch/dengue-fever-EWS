### Latest Monthly Zonal Statistics

```{python}
#| echo: false
#| label: tbl-zonal-stats
#| tbl-cap: "Latest monthly zonal statistics by SEA admin-1 region (raw, pre-correction)."

regions = stats.get("regions", {})
if not stats_path.exists() or not regions:
    print("⚠️  No zonal statistics found — the monthly zonal statistics now feed data/processed/env/SEA_env_monthly_v2.csv on the cluster (repo-root Snakefile, env_table_v2).")
else:
    rows = []
    for region, vals in regions.items():
        row = {"Region": region, "Country": vals.get("country", "")}
        row.update({k: round(v, 3) for k, v in vals.items() if k not in ("country",)})
        rows.append(row)
    df = pd.DataFrame(rows).set_index("Region")
    display_cols = ["Country", "precipitation_sum", "temperature_2m_mean",
                    "LST_Day_1km_mean", "NDVI_mean", "EVI_mean"]
    display_cols = [c for c in display_cols if c in df.columns]
    df[display_cols].style.format(precision=3)
```

### Applied Climate Deltas (SEA)

The table below shows the bias correction delta applied to each SEA feature this month.
A negative delta means the current climate is warmer/wetter than the 2011–2018 baseline,
so the raw observation is shifted downward before model inference.

```{python}
#| echo: false
#| label: tbl-deltas
#| tbl-cap: "Per-variable climate deltas (2019–2026 observed minus 2011–2018 baseline) applied this month."

current_month = target_month[-2:] if len(target_month) >= 2 else "01"
month_deltas = deltas.get(current_month, deltas.get("annual_mean", {}))
if not deltas_path.exists() or not month_deltas:
    print("⚠️  No climate delta file found — run site/scripts/apply_climate_delta.py first.")
else:
    delta_df = pd.DataFrame([
        {"Feature": feat, "Delta (subtract from obs)": round(val, 4)}
        for feat, val in month_deltas.items()
    ]).set_index("Feature")
    delta_df
```

### Global Warming Level Projections (SEA Domain)

Summary of regional climate trajectories from the GWL dataset covering the SEA domain.

```{python}
#| echo: false
#| label: fig-gwl
#| fig-cap: "Temperature and precipitation trends across Global Warming Levels for the SEA region."

import plotly.graph_objects as go
import pathlib, pandas as pd

gwl_path = pathlib.Path("../climate-projection-module/data/processed/TSV/GWL_NetCDF/gwl_all_sliced.tsv")

if not gwl_path.exists():
    print("⚠️  GWL TSV not found — run climate-projection-module pipeline first.")
else:
    gwl = pd.read_csv(gwl_path, sep="\t", parse_dates=["time"])
    gwl_monthly = gwl.groupby(["gwl", gwl["time"].dt.to_period("M")]).mean(numeric_only=True).reset_index()
    gwl_monthly["time"] = gwl_monthly["time"].astype(str)

    fig = go.Figure()
    for gwl_val in sorted(gwl_monthly["gwl"].unique()):
        subset = gwl_monthly[gwl_monthly["gwl"] == gwl_val]
        fig.add_trace(go.Scatter(
            x=subset["time"], y=subset["temp_avg"],
            mode="lines", name=f"GWL {gwl_val}°C",
        ))
    fig.update_layout(
        title="Mean Temperature by Global Warming Level — SEA",
        xaxis_title="Month", yaxis_title="Temperature (°C)",
        legend_title="GWL Scenario", height=400,
    )
    fig.show()
```
